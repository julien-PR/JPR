# My simple memory library

## Description

This is a simple memory library that i use in my personal projects.

## Instructions

To use this lib, you can add the header in the necessary files, and add `#define JPR_LIBMEM_IMPLEMENTATION` in **only one** of them to get access to the function definitions.

It should look something like:

```C
#define JPR_LIBMEM_IMPLEMENTATION
#include "libmem.h"
```
